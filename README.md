# Wordkeep / Idiomkeep

英単語・熟語の間隔反復（SRS）学習PWA。単体HTMLファイルで動作し、データは端末内の localStorage にのみ保存されます。

- `index.html` — Wordkeep（単語）
- `idiomkeep.html` — Idiomkeep（熟語・イディオム）。ヘッダーのボタンで相互に切り替え可能

## 機能

- 単語/熟語の追加・検索・編集・削除（重複追加は防止）
- フラッシュカード（暗記用、復習スケジュールには影響しません）
- 4択 / 入力式クイズ。4択の誤答はスペル/意味が似たものを優先的に選出（レーベンシュタイン距離の重み付きサンプリング）
- 間隔反復スケジュール（正解で 1→3→5→7→14→20→30→60→90日後に再出題）。不正解でも間隔は**1段階戻るだけ**で、最初には戻りません（例: 90日→60日）。間違えた単語はその場でもう一度出題され、そこで正解しても元の間隔には戻さず、1段階戻した間隔から再開します（`lapsed`フラグで管理。これが無いと「間違える→すぐ正解」で元の間隔に復帰してしまい、ミスが実質ノーペナルティになるため）
- Wordkeep: 辞書API（dictionaryapi.dev）＋翻訳API（MyMemory）による単語検索（ログイン不要）。英英辞書の定義も対象言語に翻訳して表示
- Idiomkeep: 入力中に内蔵の熟語データベース（約190個）から候補をオートコンプリート表示。選択すると意味が自動翻訳される。カラーテーマは辞書の表紙をイメージした濃緑
- 両アプリとも、入力中にDatamuse API（無料・キー不要）でオートコンプリート候補を追加表示。
  辞書/熟語データベースに見つからない語には「もしかして」でスペル修正候補（定義付き）を提案
- 多言語対応：日本語 / English / 中文 / Français / العربية / 한국어 / Русский（UI表示と訳の言語を設定で切替、アラビア語はRTL対応）
- Wordkeepに学習の記録画面（ヘッダーの🔥バッジ、または 設定 > 記録 から）。現在／最長の連続日数、学習した日数、通算正答率のタイル、直近14日の復習数の棒グラフ、半年分（26週）のGitHub風コントリビューションカレンダー（4段階の濃淡・セルにツールチップ）。集計元は各単語の`hist`（クイズの解答のみ。フラッシュカードはSRSに影響しない設計のため含まない）で、自分の単語帳（`wordkeep.v2`）とパッケージ（`wordkeep.packages.v1`）の両方を合算。日付の集計は既存のSRSと同じローカル暦日基準。`hist`は1単語あたり50件までなので、極端に復習の多い単語は古い分が切り捨てられる
- Wordkeepは単語の発音再生に対応（Web Speech API／オフライン・APIキー不要）。リスト・単語帳の表裏・クイズ・検索結果の🔊ボタンで再生。設定 > 発音 で自動再生のオン／オフ、アクセント（米／英）、速さ（ふつう／ゆっくり）を選択可。クイズは「意味→単語」出題のときだけ再生を出さない（答えの読み上げになるため）。macOSはネタ音声（Albert等）が一覧の先頭に並び、`default`音声はOSのUI言語（日本語）になるため、標準音声名（Samantha/Daniel/Google US English等）を優先して選択。非対応ブラウザでは発音セクションごと非表示
- Wordkeepはライト／ダークテーマ対応（設定 > 表示）。「自動（端末の設定に追従）／ライト／ダーク」を選択でき、基本の紺＋ゴールドはそのままに白い面を落ち着いたダークグレーへ切替。全色をCSS変数化し`:root[data-theme="dark"]`で上書き。自動時は`prefers-color-scheme`に追従（フォーカス／可視化時に再判定するフォールバックあり）、`<meta name="theme-color">`も同期
- テーマ別の単語パッケージ（Wordkeepのみ）：あらかじめ用意した配布デッキを、リスト/単語帳/復習の各画面上部の単語帳セレクターから切り替えて学習。パッケージごとにコンプリート率（%）を表示し、進捗は自分の単語帳（`wordkeep.v2`）とは別キー（`wordkeep.packages.v1`、パッケージID＋英単語で一意）で完全に分離管理。収録は「語学留学の英単語 Part1 / Part2」（各50語）。タイトル・単語の意味とも対応7言語すべてに翻訳済みで、表示言語に合わせて自動切替。リスト検索は単語・意味（全7言語）に部分一致
- 初回起動時のチュートリアル（お試し単語/熟語5つを自動追加）、アップデート後の「更新のお知らせ」、設定 > ヘルプ下に全リリースの更新履歴
- Wordkeepはインストール可能なPWA（`manifest.json` ＋ `service-worker.js`）。Android/Chromeではブラウザからホーム画面追加（インストール）を促され、追加後はオフラインでも `index.html` / `idiomkeep.html` を開けます。`icon-192.png` / `icon-512.png` は暫定プレースホルダ（濃紺角丸＋「W」）で、正方形のロゴが用意でき次第そのまま差し替え可能
- ダブルタップでのズームを無効化（`touch-action:manipulation`）
- JSONバックアップの書き出し・読み込み

## 使い方

`index.html` / `idiomkeep.html` をそのまま開くか、GitHub Pages などで公開するだけで動作します。ビルド手順は不要です。

## データについて

単語データはブラウザの localStorage にのみ保存され、サーバーには送信されません（単語検索時に辞書・翻訳APIへ単語を送る場合を除く）。端末を変えたりブラウザデータを消すと失われるため、設定タブから定期的にバックアップ（JSON書き出し）することを推奨します。

Wordkeepでは消失対策として次の2つを入れています（`wordkeep.v2`の設定に保存）:

- **永続化の要求**: `navigator.storage.persist()` でブラウザの自動削除（iOS Safariは未インストールのサイトを約7日で削除）からの除外を要求。空の初回訪問では要求せず、単語が存在するときだけ・1セッション1回だけ要求します（Chromeはエンゲージメント基準で判定するため、データがある状態のほうが通りやすい）。状態は 設定 > データ > データの保護 で確認でき、手動で再要求も可能
- **バックアップの催促**: 10語以上あり、かつ「一度も未バックアップ」「前回から14日経過」「前回から20語追加」のいずれかでリスト画面に警告バナーを表示（「あとで」で7日スヌーズ）。書き出すと最終バックアップ日時と語数を記録。パッケージ表示中はユーザー資産ではないので出しません

## アクセス解析について

Google Analytics 4（gtag.js）で匿名の利用状況（画面遷移、単語/熟語の追加・削除、復習・クイズの開始/完了と正答率など）を計測しています。`GA_MEASUREMENT_ID`（各ファイル冒頭の`G-XXXXXXXXXX`）を実際の測定IDに差し替えるまでは計測は動作しません。`localhost`/`127.0.0.1`/`file://`など開発環境では常に無効化されます。`app_name`パラメータ（wordkeep/idiomkeep、将来slangkeepも同一プロパティで）で複数アプリを横断比較できます。設定画面にも計測している旨を記載しています。
